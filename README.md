# Student Performance Dashboard

## Week 5 Final Project

The Student Performance Dashboard is a responsive mini web application developed as the final project of the frontend development internship.

## Features

- Responsive dashboard layout
- Dynamic data loaded from JSON
- Student statistics
- Subject performance chart
- Student leaderboard
- Search functionality
- Course filtering
- Sorting by name and marks
- Pass/fail status
- Dark mode
- Accessible form labels
- Semantic HTML
- ARIA labels
- Keyboard-friendly controls
- Responsive tables
- Reduced-motion support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
